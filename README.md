# Zeus Frames — Website prototype

Responsive marketing site for Zeus Frames (Toronto media studio), "Viewfinder" concept.
One page shell with client-side routing on clean paths (matching the client blueprint):

| URL | Page |
|---|---|
| `/` | Home |
| `/motherhood-family/` | Maternity, Newborn & Family (`#journeys`, `#faq` anchors) |
| `/fashion-branding/` | Fashion & Personal Branding |
| `/commercial-music-video/` | Commercial & Music Video |
| `/studio-rental/` | Studio Rental |
| `/packages/` | Packages — service tabs, plan picker, live estimate |
| `/portfolio/` | Portfolio |
| `/about/` | About |
| `/contact/` | Contact — `?service=maternity|newborn|family|kids|journey|fashion-branding|commercial-video|studio-rental` pre-fills the form |

`/commercial-video/` and `/experience-pricing/` stay alive as aliases of the two pages that were renamed.

Legacy `#hash` links still resolve. Each path is a folder with a copy of `index.html`.

## Updating from a new design export

```bash
bash apply-site.sh "/path/to/Zeusframes Site v2.dc.html"   # writes index.html
bash build-pages.sh                                        # regenerates the path folders
```

`apply-site.sh` re-applies the deployment changes the raw export does not carry: local media,
path routing, the `?service=` prefill, landing on the inquiry form, and one runtime fix. It
stops with an error if the export's markup moved, so the patch gets reviewed rather than
silently half-applied. Run `build-pages.sh` on its own after hand-editing `index.html`.
Single breakpoint at 760px: the same file renders the phone and desktop layouts.

- `index.html` — the site (desktop + mobile), generated by `apply-site.sh`
- `type-specimen.html`, `glyphs.html` — type and glyph references from the design bundle
- `logo-animation.html` — isolated logo draw-in animation
- `support.js` — prototype runtime (loads React from a CDN)
- `assets/` — logo files, `img/` photos, `video/` web-optimized clips (1080p, no audio)
- `HANDOFF.md` — full design handoff notes (tokens, pages, motion)
- `source/` — client blueprint and packages PDFs (source of truth for copy and prices)
- `uploads/` — project brief PDF
